# 🏧 ATM Management System

A command-line ATM Management System developed in Python using Object-Oriented Programming (OOP). The application simulates basic ATM operations such as PIN authentication, balance inquiry, cash withdrawal, and cash deposit through an interactive menu-driven interface.

---

## 📖 Overview

The ATM Management System is a beginner-friendly Python project designed to demonstrate the practical implementation of Object-Oriented Programming concepts. Users authenticate themselves using a PIN before accessing various banking operations.

The project focuses on creating an interactive command-line application while reinforcing fundamental Python programming concepts.

---

## ✨ Features

- 🔐 PIN Authentication
- 💰 Balance Inquiry
- 💵 Cash Withdrawal
- 💳 Cash Deposit

- 🚪 Exit Functionality

---

## 🔄 Program Flow

1. User inserts ATM card.
2. User enters the PIN.
3. PIN is verified.
4. User selects an operation:
   - Check Balance
   - Deposit Money
   - Withdraw Money
   - Exit
5. Balance is updated after every transaction.
6. User can continue performing operations or exit the application.
