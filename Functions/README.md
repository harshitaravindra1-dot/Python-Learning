# 🧠 Python Functions

This folder contains my practice programs while learning **functions in Python**. These exercises helped me understand how to write reusable code, pass data to functions, return values, and apply function-related concepts to solve problems.

## 📚 Topics Covered

- Function definition
- Parameters and arguments
- Return values
- Default parameters
- Keyword arguments
- Variable scope (Local and Global)
- Global keyword
- Lambda functions (Basic)

## 📂 Programs

### 📄 functions.py
Demonstrates the fundamentals of Python functions, including:
- Functions without parameters
- Functions with parameters
- Return statements
- Default parameters
- Keyword arguments
- A simple calculator using functions

### 📄 scope.py
Demonstrates variable scope in Python:
- Global variables
- Local variables
- Using the `global` keyword
- Variable shadowing (same variable name in different scopes)

### 📄 lambda.py
Basic examples of lambda functions:
- Square of a number
- Addition of two numbers
- Finding the maximum of two numbers
- Converting text to uppercase

### 📄 prime.py
Checks whether a number is prime using a function.

### 📄 factorial.py
Calculates the factorial of a number using a function.

### 📄 fibonacci.py
Generates the Fibonacci sequence using a function.

### 📄 palindrome.py
Checks whether a given string is a palindrome using a function.

## 🎯 Learning Outcome

After completing these programs, I gained a solid understanding of:
- Writing reusable functions
- Passing and returning values
- Organizing code into smaller modules
- Understanding variable scope
- Using basic lambda functions
- Applying functions to solve programming problems
