# 🐍 Python Strings

## 📖 Overview

This folder contains my hands-on practice while learning **Python Strings**. The programs in this module cover string creation, indexing, slicing, built-in string methods, and practical problem-solving. Each program was written to strengthen my understanding of Python fundamentals and improve my problem-solving skills.

After completing this module, I am able to:

* Create and manipulate strings in Python
* Access characters using positive and negative indexing
* Extract substrings using slicing
* Use commonly used string methods effectively
* Traverse strings using loops
* Solve practical string manipulation problems
* Apply logical thinking to solve beginner-level programming challenges
