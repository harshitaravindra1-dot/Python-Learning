# ⚠️ Python Exception Handling

## 📖 Overview

This folder contains my practice programs while learning **Exception Handling in Python**. Through these exercises, I learned how to prevent programs from crashing by handling runtime errors gracefully. I also explored how to use exception handling with user input, files, lists, dictionaries, and menu-driven programs.

# 🎯 Learning Objectives

After completing this module, I am able to:

- Understand what exceptions are.
- Handle runtime errors using `try` and `except`.
- Use `else` and `finally` blocks appropriately.
- Handle multiple exceptions in a single program.
- Raise custom exceptions when required.
- Build programs that continue running even when errors occur.
